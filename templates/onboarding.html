Step 4: Tour Your Core Workspace Tools

The main pages of the dashboard:

{{ page_icon('search', 24) }}

Results

Every stored result with its position, snippet, label, and confidence. Filter by country, label, or engine.

{{ page_icon('trend', 24) }}

Overview

How the share of positive and negative results changes run to run, Wins, and what changed since the last run.

{{ page_icon('compare', 24) }}

Compare

Compare two search dates side by side to see what appeared, moved, or disappeared.

{{ page_icon('scale', 24) }}

Review Queue

Results no rule could decide wait here for a human label. A human verdict is kept on later reclassification.

{{ page_icon('camera', 24) }}

Evidence

Downloaded HTML of newly negative result pages, with each file's SHA-256 hash.

{{ page_icon('calendar', 24) }}

Timeline

Correlate real-world events (press releases, product launches, PR responses) with ranking changes over time.

{{ page_icon('reports', 24) }}

Export

Download a PDF summary or an Excel workbook of the stored results.
