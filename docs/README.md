# docs/

Images referenced from the main `README.md`. All of them show the synthetic
"Jordan Ashworth" demo (see `DATA.md`). None show real data.

- `demo.gif`: a short walkthrough (onboarding guide, dashboard home, diff,
  review queue, evidence snapshots).
- `screenshots/*.png`: full-size 1280x800 captures of `/onboarding`, `/`,
  `/diff`, `/review`, and `/evidence`.

All of them are generated by `scripts/capture_demo_screenshots.py`, which
seeds a throwaway database with `scripts/seed_demo_data.py` (the same seed
`make run` uses), serves it locally with the scheduler off and no
credentials, and captures the pages with headless Chromium. Re-run it
after any UI change so the images keep matching what a fresh `make run`
shows:

```
.venv/bin/python scripts/capture_demo_screenshots.py
```
